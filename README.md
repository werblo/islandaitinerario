# Ricerca nuvole: dati del test approfondito

Branch di soli dati, aggiornato ogni mattina di ottobre dal workflow
"Ricerca nuvole" (`.github/workflows/ricerca-nuvole.yml` su `main`):

- `previsioni.csv`: le previsioni delle nuvole delle 7:30 per la notte
  successiva, su Reykjavík, Keflavík e Vestmannaeyjar, con 6 modelli;
- `RISULTATI.md`: il confronto con il cielo osservato (METAR e SYNOP),
  rifatto ogni giorno con i dati raccolti fin lì.

Non serve al sito: GitHub Pages pubblica solo `main`.
